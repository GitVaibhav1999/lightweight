S1Home

Your history as cards, newest first, and the two ways to start. The next workout is picked for you; a fresh session needs no template.

  • 1

    Week dots — filled = trained, outline = today. Tap → S8 calendar.

  • 2

    One card per past session: workout name, when, duration, then each exercise with top set, PR tag and overload badge. Tap a row → S4, the card → its summary.

  • 3

    Bottom dock (glass): Start next = the loop's next workout, big and neon. Fresh workout = empty session, add exercises as you go. Nothing else on this screen is tappable except cards.

Selector rule · next = the workout after the last completed session's workout in the active routine loop, wrapping. Fresh sessions don't move the pointer. >10 days idle → the dock asks "Restart from Legs?".

S2Active session

Full-screen. No rest timer, no chrome — last time's numbers are prefilled, you repeat or beat them.

  • 1

    Header: workout name, elapsed time, close. Closing without finishing keeps the session as a draft; it doesn't advance the loop.

  • 2

    Set rows. Ghost text = last session's same set; tapping ✓ with nothing typed repeats it, typing overrides. No progression maths in Phase 1. Set 2 shows the PR moment: the row lights neon with the new e1RM the instant the set is checked — this is the reward UI, and the only animation in the app.

  • 3

    Remaining exercises collapsed to their first set until you reach them.

  • 4

    Add exercise mid-session → S7. This is how a fresh session is built.

  • 5

    FINISH is outlined — the neon action on this screen is ✓.

PR rule · a set is a PR when its e1RM = w × (1 + r/30) beats the exercise's all-time best. Checked per set, not per session.

S3Session summary

The payoff. Records first, then the verdict per exercise, then back to Home — where this session is now the top card.

  • 1

    Three numbers: duration, PRs set (neon), exercises that went UP.

  • 2

    Per exercise: PR tag if any set was a record, top set, streak, badge. Tap → S4.

  • 3

    A fresh session can be saved as a Workout entity here, so it can join a routine later.

  • 4

    DONE commits and advances the loop pointer.

Badge rule (session e1RM vs. the exercise's previous session) · UP higher · HELD equal · DOWN lower · STALL = not UP three sessions running. Streak = consecutive UP sessions; resets on DOWN, not on HELD.

S5Routines & workouts

Workouts are standalone entities. A routine is an ordered loop of them. Exactly one routine is active — that loop is what the selector walks.

  • 1

    Active routine. Reconstructed from your Hevy titles on import (workouts used ≥ 3× in the last 120 days); rename freely.

  • 2

    Loop order = drag order. Neon dot = where the pointer sits. Tap → S6.

  • 3

    Add any existing workout to the loop.

  • 4

    All workouts, in the loop or not, with how often you've done them. New workout → blank S6.

S7Exercise picker

Sheet over S6 (or S2 in a fresh session). 1,312 library exercises plus yours, one search box, two chip rows.

  • 1

    Search by name. Target chips first (19), equipment chips second (top 5 + more). Chips pre-select the workout's dominant target.

  • 2

    In your workouts first — exercises you already log, with last top set. Then Recent.

  • 3

    Library rows: 40 px thumbnail · name · target · equipment · +. Tap adds and returns, no confirm.

  • 4

    Create custom: name · target · equipment · load type. Face Pull, Cable Fly Crossovers and 5 more of yours are customs — not in the dataset.

Load type derived from the dataset: cardio → time · body weight / assisted → bodyweight + reps · else weight + reps. Editable per exercise.
